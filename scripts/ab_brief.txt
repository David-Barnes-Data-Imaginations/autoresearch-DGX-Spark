PROJECT BRIEF (nano_mythos, looped transformer research on DGX Spark):
- Model: ~9M params, dim 256, vocab 8192, 2 prelude layers -> 1 shared recurrent layer looped up to 8 times -> 2 coda layers. Input reinjection each loop via a stable LTI injection (Parcae, spectral radius ~0.95) with normalised prelude output; RoPE loop-index rotation; Mixture-of-Depths (50% capacity per loop); Hyperloop multi-stream residual (K=4); Muon optimizer. Baseline loop count is adaptive: Poisson-sampled depth per sequence (mean 8) + ACT halting; it averages ~2.3-3.5 loops. A ponder-loss variant collapsed halting to ~1.5 loops.
- RA-15 (1200 steps, matched settings): adaptive baseline val_bpb 2.288874 (529 s train); fixed 2 loops val_bpb 2.288732 (313 s, 41% less train time). Fixed 4 and 8 still running.
- Planned: RA-16 depth x loops at matched FLOPs (8x1, 4x2, 2x4 layers x loops); RA-16b prelude:recurrent:coda ratio towards 2:5:2; RA-17 ELT-style intra-loop self-distillation (student at random shorter loop count matches full-loop teacher); RA-18 per-step loop-count sampling {4,6,8}; RA-19 12-16 loops; RA-20 nGPT unit-norm states with slerp residual alpha; RA-21 Dory-style reinjection norm(state + input).
- Dory 1.0 4B model card facts: input/recurrent/output = 8/20/8 layers, shared recurrent block, input reinjected every loop, loop count 1-4 chosen at inference (2 recommended; most gain from the second loop), one checkpoint serves all loop counts, last-loop KV cache option, nGPT backbone, 6T tokens NVFP4 then BF16, 256K context extension, SFT + GRPO. Training loop schedule not published.
- Recent papers: "Adaptive-Depth Is a Finishing Stage" (train fixed-depth for 67-80% of steps then sample depths), "Looping Beyond Twice" (residual scaling, decaying input reinjection, per-loop routers), StateLoop (gated persistent per-token state across loops), "Shared Memory in Looped Transformers" (loop 1 writes KV, later loops read with short window), LoopFold (predictor/corrector parallel loops).
- Goal: stable fixed-loop training, then scale to 1B on two DGX Sparks (~30 days, Muon, ~3-4B tokens of Dolma 3 + Nemotron-CC mix).
